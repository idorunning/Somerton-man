# Somerton Man code research

A reproducible research repository for testing the hypothesis that the Somerton Man code may encode a rail or tram travel itinerary.

## Repository structure

- `docs/` — hypothesis, evidence, chronology, methodology and research decisions
- `data/` — structured station data and review queues
- `src/` — extraction, mapping and RPFA analysis tools
- `app/` — browser-based map
- `tests/` — automated checks
- `source-manifests/` — provenance records for source material

## Research principles

1. Separate verified evidence from inference.
2. Record provenance for every data point.
3. Preserve uncertainty rather than forcing a match.
4. Keep analysis reproducible and decisions auditable.

## Status

Initial project scaffold. Data and analytical code will be added as sources are assessed.
