# Chronology

Dates and times should use the form `YYYY-MM-DD HH:MM` where known. Preserve uncertainty explicitly.

| Date/time | Event | Location | Evidence IDs | Certainty | Notes |
|---|---|---|---|---|---|
| 1948-12-01 | Body discovered at Somerton Beach | Somerton, South Australia |  | reported | Add primary-source citation |

## Rules

- Keep event date separate from publication or discovery date.
- Use date ranges where an exact time is not established.
- Link every material entry to the evidence register.
- Record conflicting accounts as separate rows.
