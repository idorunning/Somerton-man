# Finding — the limits of letter coverage

Reviewed 5 September 2026.

With a fixed candidate place pool, every string containing the same distinct letters has the same coverage. Reordering those letters cannot change that outcome. This is a mathematical property, not a new empirical validation of the historical place pool.

Prior work reported full coverage of the inscription's alphabet by Adelaide-reachable places. The exact producing dataset and program were not recovered; date, locality type and reachability still require source checks. No claim is made here that the distribution is statistically unremarkable or that every proposed candidate was accessible in 1948.

The default working transcription has 44 active characters and 17 distinct letters. Sixteen is a valid count for the M/M/C variant; it is not intrinsically an arithmetic error. The short physical second line is treated as cancelled in the main run and kept separate for sensitivity work.

Coverage can expose missing candidates under a fixed model, but cannot establish letter order, connectivity or purpose. The next discriminating test must examine complete ordered journeys with a frozen vocabulary, encoding rule and transport model, and compare equally optimised controls.
